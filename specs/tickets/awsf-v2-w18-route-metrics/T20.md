  Every GPT row is route-attributed: pi echoes the model it was asked for and never reads the

  Give Frontier a badged list: one point per route key whose rows are unrankable for exactly
    one reason, route-attributed identity, computed with the same x and y as a ranked point.
    A route that also has rankable rows is placed as a ranked point only. Rows unrankable for
    partial usage or degraded observability are not plotted, and excluded counts them alone.
  Badged points never join points, the Pareto line, verdicts, recommend, the advisory or the
    Matrix's rankings. verdicts() and the readout's output are byte-identical to today's.
