## What this ticket is

The milestone's **testing ticket**: one replay end to end on the fixture route over a throwaway repository, so the pinned base and the seed commit are real Git objects. No provider is called.

The shared conventions (execution, the write boundary, the owner gates, the never-do list)
are in [`./README.md`](./README.md) and Section A of the build prompts, and apply unchanged.

The `## Handoff` section below is empty at authoring. The owner appends dated, numbered entries
(C1, C2, …) there at landing, from the findings earlier tickets return in their envelopes. It holds
no placeholder because a shift hands that section to the builder after the prompt as text that
wins over it. It sits above the prompt because the sync fence compares everything after the prompt
heading with Section B byte for byte.

`routeArmProtocol` returns `null` there. Run two replays of the synthetic item on two fixture arms,

**C11. The observed model is the launched selector, and no runner has proved it.** The bridge
passes the row's `route.provider` and `route.model` as observed, because an arm names a selector

that reads `model-mismatch` there is a finding to report, not a test to loosen.

**C12. Task ids reach shared refs (for C7).** The candidate ref
`refs/awsf/candidates/<project>/<task>/<attempt>` is written in the canonical repository at

task id that names a seeded defect class. Any other text in a task id stays readable there by a
reviewer that can read outside its tree.
