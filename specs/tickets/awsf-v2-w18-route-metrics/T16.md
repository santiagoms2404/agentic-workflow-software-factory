## What this ticket is

An **implementation** ticket for D5: the evidence Marimba shows the owner at preflight, printed by the command it already runs, plus a fence that makes "the runner never routes on this" a test.

The shared conventions (execution, the write boundary, the owner gates, the never-do list)
are in [`./README.md`](./README.md) and Section A of the build prompts, and apply unchanged.

The `## Handoff` section below is empty at authoring. The owner appends dated, numbered entries
(C1, C2, …) there at landing, from the findings earlier tickets return in their envelopes. It holds
no placeholder because a shift hands that section to the builder after the prompt as text that
wins over it. It sits above the prompt because the sync fence compares everything after the prompt
heading with Section B byte for byte.

## Handoff

### 2026-09-28 — from T06 (delivered as `fcece03`)

**C1. The metrics arm refuses unknown flags.** `main.ts` accepts only `role`, `source`,
`started-before`, `json` and `state-root`. Add `advise` to `CLI_BOOLEAN_FLAGS`, or
`--advise --plan x` throws "--advise requires a value". Add `advise` and `plan` to the allow list.
`--milestone` arrives in `parsed.milestones`, not `flags`. `doc-reconciliation.test.ts` reads
`CLI_BOOLEAN_FLAGS` as live flags.

**C2. `--json` refuses any filter.** Recommended: `--advise` refuses `--json` too, for the same
reason.

**C3. The fence does not reach the CLI.** `core/src/cli/commands/metrics.ts` and `shift.ts` are
outside the advisory fence's paths, so `awsf shift plan` may import the advisory.
`readMetricsPayload(dbPath, extractedAt)` is the one read. `recommend` takes
`priorLookup(observedModels(rows))` and `payload.untestedRoutes` (T06 C8).

**C4. One flag, two vocabularies.** The table's `--role R` takes any role, and `--advise`'s takes
`builder|reviewer`. Validate the narrow set only in advise mode.
