## What this ticket is

An **implementation** ticket. With an active lease, a run no longer exits at a stop it can handle: the Delegate acts, journals, notifies and continues in the same foreground process.

The shared conventions (what Jev is, execution, the write boundary, the owner gates, the
never-do list) are in [`./README.md`](./README.md) and Section A of the build prompts, and apply
unchanged.

The `## Handoff` section below is empty at authoring. The owner appends dated, numbered entries
(C1, C2, …) there after delivery, from the findings earlier tickets return. It sits above the
prompt because the sync fence compares everything after the prompt heading with Section B byte
for byte.

## Handoff

### 2026-09-29 — from T05 (delivered as `364f15d`)

**C1. The hook is in main.ts.** `shadowStop` in `core/src/cli/main.ts` runs
`recordShadowProposal` (`core/src/delegate/shadow.ts`) after `awsf run`, `awsf resume` (only
when confirmed) and `awsf intake` return, and after `awsf run` throws. It swallows every error
so the command's output and exit code never change. drive should run after it. It reads the
latest proposal with `readTaskDelegateProposals(dirname(attemptDir)).at(-1)` and checks that its
`sessionId` and `statusRevision` match the current status. drive must not swallow its own
errors the way the shadow step does.

**C2. Raise payload.** `{ act: "raise", calls, raiseActs, finalCeiling }`: `calls` is
`finalCeiling - ceiling` from `raiseActsNeeded` and can exceed `MAX_GRANT_CALLS` (5). Perform
it as `raiseActs` grants of at most 5 calls each, each one journaled.

**C3. The quota plan is a placeholder shape.** `QuotaPlan` in `core/src/delegate/policy.ts` is
`{ kind: "resume-now" } | { kind: "wait-until", at } | { kind: "stop", reason }`. Nothing
passes one yet, so every quota-pause and L26 proposal is wait-for-owner with
`quota-plan-absent`. Pass T10's result as `ShadowInput.quotaPlan`, and align the two types
rather than adapting one to the other.

**C4. Only `executable: true` may be acted on.** land-shadow and wait-for-owner are never
executable, and `assertDelegateProposal` refuses a record claiming otherwise. A cancel
proposal is `jev-picked`, which makes it judgment, not code-decided, even though the plan
lists cancel among the acts live from the first lease. T06's autonomy decides; drive should
not assume.

**C5. Tests never reach Jev live.** Under `NODE_TEST_CONTEXT`, `shadowStop` withholds
`OPENROUTER_API_KEY`, and the key is set in the owner's WSL login shell. drive's tests should
inject a transport (`ShadowInput.transport`) and should not depend on the environment.
