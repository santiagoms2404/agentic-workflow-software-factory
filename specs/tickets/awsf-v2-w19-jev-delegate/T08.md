## What this ticket is

An **implementation** ticket that writes a protected path. It adds the delegate actor to exactly the edges the delegated acts traverse, and one authority type every owner-act command accepts. The task-machine change is gate G19-S: written in a manual session only with the owner's explicit authorization, and committed as the owner's.

The shared conventions (what Jev is, execution, the write boundary, the owner gates, the
never-do list) are in [`./README.md`](./README.md) and Section A of the build prompts, and apply
unchanged.

The `## Handoff` section below is empty at authoring. The owner appends dated, numbered entries
(C1, C2, …) there after delivery, from the findings earlier tickets return. It sits above the
prompt because the sync fence compares everything after the prompt heading with Section B byte
for byte.
