## Handoff

### 2026-09-29 — from T01 (delivered as `ed7e71c`, `6b1751d`, `56a8101`)

**C1. Marimba builds its own transport, and `projectSwitch` is required.** Construct
`new JevTransport({ projectSwitch })` from `core/src/decision/jev-transport.ts`. Reading AWSF's
own `awsf.project.yaml` through `jevSwitchOf(loadCatalog(…))` lets the owner's `decision.jev: off`
bind Marimba too; passing `"on"` bypasses it. That choice is the owner's. Ask rather than
default.

**C2. `core/src/decision/pi/jev-compact.pi.ts` is inside the fence.** No `fetch`, and no
endpoint string: call `ask()`. The transport imports `../policy/redaction.ts`, which imports
`../../../dashboard/shared/credential-patterns.ts`. The extension works when pi loads it from
the checkout, and breaks if the file is copied elsewhere.

**C3. Falling back (INV-5) is immediate.** Without `OPENROUTER_API_KEY` in the pi session's
environment, `ask()` returns `unavailable` / `missing-key` at once, with no request. Treat
anything but `answered` as tier `silent`, today's behaviour. The default deadline is the full
30 s. `turn_end` should pass a shorter `deadlineMs` (any positive integer up to 30 000), or an
`AbortSignal` through `ask(state, questions, { signal })`, which returns
`unavailable` / `aborted`.

**C4. Cut-point options are string keys, at most 255.** Choice criteria keys are strings, and
JavaScript orders integer-like keys (`"0"`, `"1"`, …) numerically ahead of `"none"`. Request
validation refuses more than 255 options, so cap the turns offered at 254 plus `none`.
