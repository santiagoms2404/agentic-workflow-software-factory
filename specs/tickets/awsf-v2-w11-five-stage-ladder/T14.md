## What the reach is read for

Nothing imports a driving document — the tree is markdown. So the walk resolves the transitive
relative-import closure out of `core/src/stages/**` exactly as `quota-fence.test.ts` does, and then
reads each reachable file for the PATH LITERALS it spells: a bare literal, the string segments of a
`join`/`resolve` call, and the fixed parts of a template. Segments are compared one at a time, so
`docs/drivings/` and `docs/design/driving-notes.md` are not matches. Comments are not scanned; a
comment naming the tree reaches nothing.

Both new legs are green as written: no file in the closure spells a `docs/driving` or `.claude`
path, and nothing in it imports `core/src/execution/**`. Two companion tests keep that from being a vacuous green — one asserts the
reach is larger than the stage files themselves, the other feeds each of the three spellings a
synthetic offender in memory.

## Both legs were seen to bite, hop by hop

A throwaway `export const DRIVING_PROBE = "docs/driving/cookbook.md";` appended to
`core/src/contracts/registry.ts` — one hop away from the stage module, the shape a direct scan
misses — failed with:

```
core/src/contracts/registry.ts:92 (driving-tree-path) "docs/driving/cookbook.md"
    via core/src/stages/contract.ts -> core/src/contracts/registry.ts
```

A throwaway `export type { CallBudget } from "../execution/call-budget.ts";` in
`core/src/stages/resolve.ts` failed the INV-5 leg with:

```
core/src/stages/resolve.ts:172 imports core/src/execution/call-budget.ts
    via core/src/stages/resolve.ts -> core/src/execution/call-budget.ts
```

Both were removed and the file returned to 8/8. The type-only import is counted as an edge for the
same reason T11 recorded: the fence is about what the module reaches, not what survives compilation.

## Why this is not `execution-isolation.test.ts` again

That file's two claims are about the launch surface: pi's `--no-skills` pinned in exact argv order,
and the absence of `.claude/` at the repository root. Neither says anything about an in-repository
reach, which survives `--no-skills` untouched and points at `docs/driving/` rather than at the root
path that file watches. The header now states all three claims side by side so a later reader does
not delete one believing another covers it.

Validation: `npm run test:unit` passed 1444/1444 tests in 283.6 seconds; `npm run typecheck` and
`npm run lint` exited 0.
