  core/test/fixtures/stages/boundaries.json - the two no-path rows
  core/test/unit/cli/_offline-route.ts - world() and the offline machinery, which
    both design-to-plan-route.test.ts and the journey import

THE CONTRACT THIS TASK ASSERTS
  W05's M8 registered the three host-command schema ids T04 routed to it, and its
  Q7 decided that a session-less command's envelope is a validated return value
  stored nowhere. So the join splits, and the split is the contract rather than a
  shortfall: typed shape everywhere, stored-envelope evidence where a session
  exists, and an explicit owner handoff where none does.

DO
  Assert typed shape for ALL FIVE stages. Each output declares the schema id its
  record names, validates against it through parse-envelope.ts, carries every
  field that schema requires, and carries every field its capture recorded.
  BY SHAPE, NOT BYTES: the captured bytes are one run's output, so only its field
  set travels into the assertion. Asserting its values would make the journey a
  snapshot test of a scripted adapter, which proves nothing about the join.
  Read S3, S4 and S5 back out of the projection through envelopesForPhase, keyed
  by the phase row the projection itself holds rather than by a built-up id. S1
  and S2 are the validated values their commands returned: Q7 stores neither, and
  reaching for a store here is the mechanism INV-6 refuses.
  At S4->S5 - the one boundary M8 made projection-observable - assert the stored
  publish envelope sits on the same session as the build stage's own stored
  envelope and names the exact revision S4 produced.
  At S1->S2 and S2->S3 assert the opposite claim, because it is the true one: the
  later stage's inputs are owner-authored and appear nowhere in the earlier
  envelope, the boundary row is no-path with no observed task state, and the
  state root holds no journal, no session and no attempt directory while the
  boundary is open. Do NOT claim a later stage derives its input from an earlier
  envelope at either.
  Record the route log at the end and assert it contains no provider launch
  beyond the scripted stub, using the RouteLog idiom rather than a count.

DO NOT
  Add a schema, a synthetic session, a host-command store, a migration, a
  lifecycle state, a legal edge, a catalog field, or an automatic stage advance.
  INV-2 and INV-6 forbid every one of them and Q7 already decided the shape.
  Do not "fix" the file-existence assertions that observe each stage's entry
  precondition. They are not the chain reconstructing a value from a file.

DONE WHEN
  npm run test:journeys is green.
  Flip this leaf plan's task 18 checklist to [x]. Do NOT touch specs/awsf-v2-plan.html.
