## Runtime and harness

`npm run test:journeys` passed **105/105** in 189.45 seconds. The new file's own case,
`core/test/journeys/five-stage.test.ts`, ran in **5.94 seconds** (`node --experimental-strip-types
--test core/test/journeys/five-stage.test.ts`, 27.5 s wall including the process's module-load
overhead, which every journey file pays). `npm run typecheck` and `npm run lint` exited 0.

**All five stages travelled; Q5's absence did not apply.** `init` → `project-register` →
`design-to-plan` → `build` → `publish`, with each boundary crossed by an owner act the test performs:
the catalog authored and committed by hand, the configuration and prompts replaced and committed,
then `awsf land` twice. The journey asserts the travelled list equals `STAGE_ORDER` rather than
counting stages. Five provider contacts, all `stub`, recorded through the `RouteLog` idiom; the
fixture provider process never ran. The only remote is a bare repository inside the temporary
directory, checked by resolving every configured remote URL back under that root.

**Do not invent a second harness — so one was removed.** The offline `world()` of
`core/test/unit/cli/design-to-plan-route.test.ts` was factored into
`core/test/unit/cli/_offline-route.ts` (the `_bare.ts` idiom `publish.test.ts` already imports across
directories). That module now owns `fixtureConfig`, `installPrompts`, `CannedStubAdapter`,
`RouteLog`, `fakeBroker`, `prepareTask`, the design/review/plan envelopes and `world()` itself.
`design-to-plan-route.test.ts` consumes it and is behaviourally unchanged (3/3 green, and
`npm run test:unit` passed 1449/1449 in 291.62 seconds afterwards); the journey consumes the same
pieces and replaces only the seeding step, because stage 1 must begin from an empty directory.

**What this file deliberately does not assert.** The stored-envelope join at each boundary is T18's
row and stays `[f]` under `W05-HOST-COMMAND-ENVELOPES`: stages 1, 2 and 5 store no typed envelope at
all. The file's header names that block rather than passing over it silently.
